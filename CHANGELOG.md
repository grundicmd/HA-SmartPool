# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-05

### Added

- Initial public HACS-ready release.
- UI configuration using iAquaLink credentials.
- Support for `cyclonext` and `i2d_robot` device types.
- Start/stop control.
- Connectivity, runtime, remaining time, error and canister sensors.
- English and Russian translations.
- HACS and hassfest validation workflows.
